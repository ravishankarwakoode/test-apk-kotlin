# APK Analyzer Pro

A Kotlin APK analysis project with both:
- a desktop Swing UI
- a backend API for uploading and analyzing APK files

## Features

- Browse APK files from the desktop UI
- Analyze Android manifest metadata
- Get package name, version, SDK values, permissions, activities, services
- Detect native libraries and META-INF files
- Calculate SHA-256 hash
- Generate and save an HTML report
- Expose a backend endpoint for API-based analysis

## Run desktop UI

```bash
gradle run
```

## Run backend

```bash
gradle run --args="--backend"
```

Backend URL:
- http://localhost:8080/health
- POST http://localhost:8080/api/analyze with multipart form field `file`

## Build

```bash
gradle build
```

## Notes

This tool inspects the APK archive and manifest without installing or executing the app.
